# TEGARIS82 FIGHT - Godot 4.3 Android

Original 3D-style fighting game prototype for Android.

GitHub Actions uses Godot 4.3 with the Android SDK configuration documented for Godot 4.3: Android Platform 34, Build Tools 34.0.0, NDK 23.2.8568313, CMake 3.10.2.4988404, and Java 17.

Run GitHub Actions -> Build TEGARIS82 Android -> Run workflow. The workflow exports `build/android/TEGARIS82-FIGHT-debug.apk`.
